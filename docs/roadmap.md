# Roadmap

1. Add user authentication, scoped authorization, quotas, and request rate limits before network deployment.
2. Move long-running run execution to a durable job queue and support concurrency-safe cancellation.
3. Add deletion and retention policies, tenant-aware data isolation, and encryption-at-rest options.
4. Add semantic embeddings behind the existing ranking interface and evaluate them on a versioned, representative dataset.
5. Add stronger verification strategies for numeric, structured, and contradictory evidence.
6. Add managed MCP server configuration, health checks, schema persistence, and credential isolation.
7. Add streaming run events and a minimal web interface after asynchronous execution semantics are established.
